# Dashboard Coverage Matrix

This matrix ensures every item from `resources/Web System.pdf` appears in the MVP dashboard.

## Coverage Levels

- `MVP Dashboard`: Must be visible in the dashboard using sample data.
- `MVP Drill-Down`: Must be available as a table or detail page.
- `Production Later`: Full workflow, automation, or integration after deal closing.

## Executive Dashboard Sections

The MVP should have these top-level dashboard pages:

1. President Overview.
2. Finance and Accounting.
3. Tug Operations.
4. Technical and Maintenance.
5. HSE.
6. Crewing.
7. Procurement.
8. Inventory.
9. HR.
10. Document Control.
11. Management KPI Dashboard.

# SEDAR Document Control Catalogue

This directory contains source documents and their reviewed field definitions.

## Intake Workflow

1. Extract all visible content from the supplied source document. Do not omit or summarize statements, instructions, notices, labels, checkbox options, table headings, or signature/closing text. Mark genuinely unreadable text as `[unclear]` for confirmation.
2. Wait for business-owner approval of the extracted fields.
3. Add the approved definition and source reference to this catalogue.
4. Add the approved metadata and source file to the Odoo `sedar_document_control` addon.
